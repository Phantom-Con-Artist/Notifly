# Security

## Reporting a problem

Please report security problems privately, not in a public issue. Use **Security → Report a vulnerability** on this repository's GitHub page. Tell us what you found and how to reproduce it. You will get a reply as soon as possible.

## Good to know

- The Notifly plugin makes no network requests and sends no data.
- Quick capture is a small separate program. Turning it on starts it with your account's permissions, so only use files from this repository's [releases page](https://github.com/Phantom-Con-Artist/Notifly/releases) and check the `.sha256` file next to each one.
- Quick capture only reads and writes inside your vault. Details are in the README under "Privacy and permissions".
